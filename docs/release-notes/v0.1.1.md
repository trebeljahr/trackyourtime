A fix release. v0.1.0 published the server image but no self-hosted client image, so a fresh self-host install had nothing to serve the web app from.

The client image's build never included `@starter/invoice-pdf`. The public invoice generator imports that package into the browser bundle, and the package's exports resolve to its build output, so the static export stopped with `Can't resolve '@starter/invoice-pdf/totals'`. The image now copies and builds it, as the hosted client image already did.

Nothing else changed. If you already run v0.1.0's server image, pull both images at v0.1.1 and restart:

```bash
docker compose -f docker-compose.selfhost.yml pull
docker compose -f docker-compose.selfhost.yml up -d
```

The [self-hosting guide](https://github.com/trebeljahr/trackyourtime/blob/v0.1.1/docs/self-hosting.md) is unchanged.
