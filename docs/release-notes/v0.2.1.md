# Track Your Time 0.2.1

Version 0.2.0 reached TestFlight and Google Play's internal track, but two build checks blocked the hosted web deployment and self-host client image. This patch fixes those checks. The app's features and sign-in flow are the same as 0.2.0.

If you host Track Your Time, update the server and client images together:

```bash
docker compose -f docker-compose.selfhost.yml pull
docker compose -f docker-compose.selfhost.yml up -d
```

See the [0.2.0 notes](https://github.com/trebeljahr/trackyourtime/releases/tag/v0.2.0) for the changes to sign-in, the phone app, time entries and the extension.
