# Track Your Time 0.3.0

Track Your Time 0.3.0 is for people who bill a team's hours, not only their own.

- **Team workspaces.** Create a workspace for a team next to your personal one, and invite people into it. Your personal workspace stays yours.
- **Invoices that track payment.** Record payments and credits, see what each client still owes, filter overdue invoices and send reminders.
- **Timesheet approval.** A workspace can ask members to submit a period. An owner or admin approves it, and an approved period is locked.
- **Rates per member.** Each person can bill at their own rate.
- **Saved report views, entry search and bulk edits.**

Time you track is safer. The web app, the browser extension and Raycast now save each change on your device before they send it. A change survives a closed tab, a restart or a lost connection, and the server applies it once.

On iOS, choosing "Take Photo" for a profile picture or invoice logo no longer closes the app.

## Updating a self-hosted server

The server runs one database migration on start (schema 1 → 2). It marks each workspace as personal or team. The migration only adds a field, so 0.2.2 can still run against the database if you roll back.

The server now needs MongoDB as a replica set: it writes each time-entry change in one transaction. Fetch the new `docker-compose.selfhost.yml` before you pull. Its `mongo` service starts as a single-node replica set and converts your existing data volume in place on the first start. If you set `MONGODB_URI` to a database of your own, that database must be a replica set or `mongos`. A standalone refuses time-entry writes with `DURABLE_REPLAY_REQUIRES_REPLICA_SET`.

Update the server and client images together:

```bash
docker compose -f docker-compose.selfhost.yml pull
docker compose -f docker-compose.selfhost.yml up -d
```
